# readywhen media

**Everything in this repository is on the open internet.**

It holds finished readywhen social creative, so the scheduling tool (Buffer) can fetch images by
address. Nothing else belongs here: no briefs, no drafts, no photos of people, no source files.

- Files arrive through `_tooling/li-media/publish.py` in the private readywhen-marketing-assets repo,
  which only accepts finished images from the folders where creative is built.
- Names are made from each file's content, so a published file is never overwritten.
- Do not edit or delete files here by hand. A post in Buffer may still point at one.
